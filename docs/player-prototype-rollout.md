# Перенос прототипа в приложение

Платформы: Android и iOS. Прототип предназначен для предварительной ручной проверки. Настройки и действия в приложении подключаются к реальному состоянию.

## Согласованные коррекции

- Неизвестный исполнитель — `Unknown`, название отдельно от исполнителя.
- Добавление музыки только иконкой в меню очереди/плейлиста.
- Боковые кнопки — предыдущий/следующий трек. Шкала позиции остаётся интерактивной.
- Единое окно выбора: файлы отмечены — импортировать выбранные файлы; ничего не отмечено — импортировать текущую папку.
- Системный выбор корневой папки выдаёт разрешение, затем встроенный браузер показывает папки и аудиофайлы вместе.

## Этапы реализации

- [x] Коррекции плеера Android/iOS, устранение дублирования исполнителя и несогласованного канала UDP.
- [x] Единый браузер папок и файлов Android/iOS (Android — сборка; iOS — исходники, полная сборка ожидает Xcode).
- [x] HTML приведён к коррекциям, исправлены ошибки имитации; 15 сценариев обработчиков прошли. Ручная визуальная проверка остаётся отдельной приёмкой.
- [x] Доводка Android: Connect/chooser, Solo, фиксированная геометрия, уведомления, очередь, плейлисты; существующие EQ, пространство и служебные экраны сохранены. `assembleDebug testDebugUnitTest` — успешно, 97 тестов. Жесты на устройстве ещё не проверены.
- [x] Перенос Solo, Connect и chooser в iOS, локальный стереовывод (исходники; требуется сборка Xcode и проверка на устройстве).
- [x] Очередь и плейлисты iOS: выбор, удаление, Undo, сохранение/переименование/добавление/замена.
- [x] Протокол fileTransferV1 для новых Android/iOS: Send, подтверждение отмены, лимиты и очистка временных файлов. Сетевой сценарий на двух устройствах ещё не проверен.
- [x] EQ и пространство iOS: элементы подключены к обработке и сохранению; реализация DSP отличается от Android, акустическая эквивалентность не проверена.
- [x] Версии и документация обновлены, доступные проверки выполнены.
- [ ] Приёмка в полном Xcode, браузере и на двух физических телефонах — не подтверждена в текущем окружении.

Для каждого законченного изменения — отдельный коммит и обновление версии соответствующей платформы. Результаты проверки фиксируются отдельно от предположений по исходникам.
