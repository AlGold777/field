# Вердикты по 375 идеям из ревью других моделей

Исходный список — [`review-ideas-375.md`](review-ideas-375.md). Каждый пункт проверен по коду Android 1.11.8 / iOS 1.3.18 (коммит `a765948`) с учётом исправлений 1.11.8 и чужого аудита [`SoundField-release-audit-292.md`](SoundField-release-audit-292.md). Решение принималось по факту в коде, а не по формулировке пункта; ссылки `файл:строка` относятся к этому коммиту.

Критерии: пользователь только слушает (без новых подтверждений, тестов и настроек в обычном UI), объём — два телефона, цель — качество звука. Публикации в магазинах сейчас нет: APK ставится на свои телефоны, iOS проверяется только typecheck. Поэтому юридические, магазинные и «защита от чужого в домашней сети» пункты в основном отложены до решения о публикации.

## План изменений (выпуск Android 1.11.9 / iOS 1.3.19)

Всё принятое — правки объёма S/M; делаются одним выпуском, пакетами по подсистемам.

1. **Звук и потоки Android.** Гонки в приёмнике Point и TCP-буфере (105, 106, 107), смена сессии под `sendLock` (120), `@Volatile` для полей из других потоков (111, 112), восстановление вывода после `Error` и сброс счётчика попыток (171, 172, 173), таймеры без догоняющих пачек (116), пробы шлюзов вне потока движка (117), честная телеметрия тика (124), не рвать живой TCP при пустом маршруте (125), повторы UDP и нулевой ключ (132, 133, 138), закрытие TCP-аудиосокета (126), порт 0 при занятом порте (113), лог без общего `SimpleDateFormat` (128), двойной подсчёт адресов (129).
2. **Воспроизведение и очередь Android.** Пауза при выдёргивании наушников в Solo (176), даунмикс 5.1 (192), утечка SRC при отмене декодирования (194), использование и отмена предзагрузки (121, 122), передача файлов (99, 102, 103), навигация и прокрутка очереди (363, 373), экран калибровки не гаснет (177), уведомление захвата с «Стоп» и точным текстом (38, 39, 42), мелкие дефекты (185, 213, 164, 159, 190, 186, 140, 139, 142, 144, 13, 18, 19, 137, 147, 148, 130, 362, 364, 365, 367).
3. **Ядро DSP и JNI.** Проверка длин и `JNI_ABORT` (233, 235), таблица true-peak при создании (241), защита от NaN в фильтрах и лимитере (242, 244, 250), тесты (255, 258, 257), прогон тестов ядра с ASan/UBSan (21).
4. **iOS.** Тик вне пары (318), пауза прерывает калибровку (325), порядок NACK (329), `Ch.name` (335), защита сериализации (337), профиль Solo на наушниках (341), ошибки `sendto` (345).
5. **Тесты Android.** DFT-тест FFT и замена копий FFT (209, 210), негативные TCP-тесты (294), политика NACK (296, 306), SyncProbe (299), дедлайн теста сцены (305), `StreamResampler` (293).
6. **Чистка кода.** Мёртвый код и именованные константы (182, 199, 201, 207, 214, 219, 221, 369, 375, 75).
7. **Репозиторий, инструменты, документация.** Артефакты сборки и APK вне индекса (59, 60), строгий режим Spotify и честный typecheck (51, 55), NDK (264), vendor-патч discovery (29), комментарий кэша (261), coretest (152, 153), лабораторные скрипты (150, 271, 272, 275, 276, 279, 280, 282), README и `audio-algorithms.md` (63, 65, 68, 70, 71, 72, 74, 76, 86), журнал версий в `docs/CHANGELOG.md` (62).

Отложенные пункты сгруппированы по условиям: публикация (2–5, 7, 10, 16, 27, 32–35, 37, 43–49, 87, 286, 359), работа над iOS и Xcode-сборка (53, 56, 58, 90, 91, 110, 247, 292, 308–316, 321, 322, 326–328, 357), CI (50, 52, 73, 151, 291, 297, 298), тестовый стенд Engine (109, 123, 154). «Нужны данные» — список замеров на телефонах (54, 77, 78, 80, 82, 97, 98, 114, 118, 156, 166, 180, 205, 260, 267, 307, 317, 320, 324).
