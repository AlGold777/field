# Лицензии корпуса sflab

Корпус — фрагменты по 20 с (48 кГц / 24 бит / стерео), вырезанные из записей с открытой лицензией (CC0, Public Domain, CC-BY). Файлы WAV и источники в репозиторий **не** входят: `python3 tools/audio-corpus/fetch.py` скачивает источники из `manifest.json`, проверяет sha256 источника, декодирует (macOS `afconvert`) и вырезает фрагмент (sha256 фрагмента тоже в манифесте). Фрагменты — модификация оригиналов (вырезка 20 с, перекодирование в WAV) в смысле CC-BY; требуемая атрибуция ниже.

**Источники с потерями** (`lossy: true` в манифесте, колонка «lossless» = нет): на archive.org для этих записей нет lossless-оригинала. Такие фрагменты используются только для метрик громкости, пиков, лимитера и баса; в метриках, чувствительных к ВЧ и шуму (спектр выше ~16 кГц, шумовая полка, оценка кодирования), не использовать. Остальные 8 фрагментов — FLAC-оригиналы.

Лицензия записана по полю `licenseurl` метаданных archive.org (проверено 2026-10-22). Права исполнителей/правообладателей мастер-записей юридически не проверены (особенно старые джазовые записи и «PD (legacy)»); корпус используется только как тестовые данные разработки и не распространяется внутри приложения.
