# Лицензии корпуса sflab

Корпус — фрагменты по 20 с (48 кГц / 16 бит / стерео), вырезанные из записей с открытой лицензией (CC0, Public Domain, CC-BY). Файлы WAV и источники в репозиторий **не** входят: `python3 tools/audio-corpus/fetch.py` скачивает источники из `manifest.json`, проверяет sha256 источника, декодирует (macOS `afconvert`) и вырезает фрагмент. Фрагменты — модификация оригиналов (вырезка 20 с, перекодирование в WAV) в смысле CC-BY; требуемая атрибуция ниже. Оригиналы большей частью MP3 (потеря: источники с потерями; для метрик ядра это допустимо, для оценки качества кодека — нет).

Лицензия записана по полю `licenseurl` метаданных archive.org на момент проверки (2026-10-22). Пункты «PD (legacy)» и «CC0» у старых джазовых записей выставлены загрузчиком; права исполнителей/правообладателей мастер-записей не проверены юридически — корпус используется только как тестовые данные разработки и не распространяется внутри приложения.
