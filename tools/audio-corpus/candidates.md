# Open-licence audio candidates for DSP test corpus

Status of this file: candidate list, not a finished corpus.

## Method

- Source: Internet Archive (archive.org). Items were searched with `advancedsearch.php` by `licenseurl` and subject tag, then each item was checked with `archive.org/metadata/<id>`.
- License: taken from the item's `licenseurl` metadata field. The item page was not separately rendered; the metadata field is the item's own license record.
- Download check: `curl -sIL <direct URL>` on the first MP3/FLAC/WAV file of each item (OGG/Opus excluded). All rows below returned HTTP 200 after redirects. Content-Length is the value from that response.
- Length: from archive.org file metadata (seconds). All rows are at least 30 s.
- Genre/role tags come from the archive.org `subject` search that surfaced the item. They are NOT audio-verified. Where a role is unconfirmed it is marked UNVERIFIED.
- Channels and sample rate: not present in the archive.org metadata for these items. Recorded as UNVERIFIED. Mono/stereo has NOT been confirmed for any row.
- Attribution: for CC BY 4.0 items, the string below is the one the license requires (title, artist, license, source URL). CC0 and Public Domain Mark items require no attribution; credit is optional and shown for reference.

## Summary

- Rows with verified license + HTTP 200 + length >= 30 s: **32**
- Rows with verified license URL but failed download: 1 (MailCentreDub, HTTP 500, excluded)
- Requirement check:
  - (a) deep sub-bass (<50 Hz): 3 candidates listed (rows 1, 3, 27). Content NOT verified spectrally; treat as candidates only.
  - (b) acoustic (solo guitar, piano, voice, string quartet): rows 5, 6, 7, 8, 9, 22, 23. Instrument tags come from subject search only.
  - (c) densely mastered loud mixes: rows 29, 30, 31. Loudness NOT measured; UNVERIFIED.
  - (d) genuinely mono PD recordings: rows 19, 20, 21 are 1930s-1950s 78 rpm era items, but mono is NOT confirmed. **Requirement not met with verified evidence.**
  - (e) classical orchestral: rows 24, 25, 26.
  - (f) vocal pop/folk: rows 9, 32 (role UNVERIFIED for 32).
  - (g) jazz: rows 18, 19, 20, 21 (roles UNVERIFIED).
  - (h) percussion-heavy: rows 16, 17 (17 UNVERIFIED).
  - (i) high-frequency-rich: rows 11, 12, 13, 14, 15 (harpsichord, bells).
- Sources not used or not reached: Wikimedia Commons (API works; the Liszt/Bolet MP3 is labelled "Public domain" but a 1960 performance's rights are not confirmed, and Piano-phrase.wav is CC BY 3.0 but only about 3-4 s, so both were excluded), Musopen (Kickstarter item had no direct file in the root listing), Free Music Archive, Freesound, ccMixter, incompetech, and Musopen were not queried in this pass.
- Edison 78 rpm items (edison-50650_01_7103, edison-50622_01_6929) were found but excluded: archive.org metadata has no license field and the item page shows no license statement.
- Sources that blocked automated fetch: none blocked by HTTP. Python `urllib` failed TLS validation in this sandbox (self-signed chain), so curl was used for all checks.
